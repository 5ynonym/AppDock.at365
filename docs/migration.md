# 独立アプリからAppletへ機能を取り込む場合

時計、壁紙、Windows操作、ブラウザ操作、Gmailは独立したAppletとして存在する。これらを未実装とする旧移行案は使わず、対象Appletの現在のコードと開発文書を確認する。マウスジェスチャーの入力基盤は[本体](gestures.md)が所有する。

追加機能を取り込む場合は、元アプリの指定された動作と独立起動の要否を先に確認する。設定・通知・コマンド・保存領域は[Applet実装ガイド](applet-development.md)に従い、専用WPF/WinForms画面やSTAメッセージループはnative Appletが所有する。移植のためだけに元アプリの設定や認証を変更しない。

## 未着手の候補

元Watchのクリップボード履歴は時計Appletの実装範囲に含まれていない。取り込みを依頼された場合は、元ソースでSTA・メッセージループ、カーソルを動かさない表示、500msの静穏待機、起動中だけの履歴保持を再確認する。この候補は新しい実装依頼や、時計Appletへの機能追加の決定を意味しない。
