# タスクトレイの設定とメニュー

0.26.10以降は「設定 → タスクトレイ」にクリック、ダブルクリック、コンテキストメニュー編集を集約します。一般・ショートカット・Applet詳細のショートカットにはトレイ編集を重複させません。

## 保存と移行

`Settings.trayMenu`が正本です。トップレベルにcommand / separator / group、group.childrenにはcommand / separatorを保存します。項目は独立したidを持ち、同じコマンドを複数位置へ置けます。グループ名は1～80文字、階層は1段、全項目は1500件以下（旧上限500コマンドにグループと一時停止を追加しても移行できる上限）、idは全体で一意です。

```json
{
  "trayMenu": [
    { "id": "open", "type": "command", "command": "appdock.open" },
    {
      "id": "daily",
      "type": "group",
      "title": "よく使う操作",
      "children": [
        { "id": "pause", "type": "command", "command": "appdock.gestures.togglePause" }
      ]
    }
  ]
}
```

`trayMenu`が未指定の旧設定だけ、discover後のコマンド一覧からApplet別グループと本体の最上位項目へ変換し、既存SettingsStoreの原子的な保存を使います。旧版で固定だった一時停止は編集可能なコマンドとして末尾に取り込みます。未取得コマンドもトップレベルへ保持します。明示した空配列はそのまま残し、解除した項目を再生成しません。

`trayCommands`は新形式が存在する場合、配置されたコマンドIDの重複を除いた派生値です。単独で編集しても新形式を上書きしません。設定/終了の旧重複項目は移行時に除きます。新形式での追加は検証エラーにし、ホスト側から必ず末尾に「設定…」「終了」を付加します。

## 編集と実メニュー

`TraySettings.tsx`はuseSettingsEditorのdraft/JSON/revision/saveを共用します。選択用CommandPaletteは実行せず、クリック先・ダブルクリック先・追加するコマンドを返します。配置操作は保存まで実メニューへ反映しません。グループへのドロップで末尾へ入り、項目へのドロップでその直前へ移動します。グループを別グループの子にはできません。上下ボタン・ハンドルの上下キーは同じ階層内で移動し、配置先の選択でトップレベルと各グループを移動します。グループ解除は子を同じ位置へ戻し、コマンドを削除しません。

shared/tray-menu.tsがプレビューと実メニューの項目を解決します。空グループ、先頭/末尾/連続の区切り線は表示しません。未知/利用不可コマンドは設定に保持して無効表示し、コマンド再登録で表示名と利用可否を更新します。Appletのtrayラベル提案は従来通り参照し、IDを実行対象とします。設定保存・外部設定編集・Applet状態/コマンド変更で実メニューを再構成します。グループ名や項目名の`&`はElectronのニーモニックとして解釈させず文字として表示します。

`appdock.gestures.togglePause`はhostCommandsと共通executeCommandへ登録します。検索・ショートカット・トレイ・クリックから実行でき、ウィンドウを開かず一時停止/再開を切り替えます。トレイ内の同コマンドはcheckboxになり、いずれの経路で実行しても全配置のチェック状態を再構成します。一時停止状態は保存せず、本体再起動で解除します。ジェスチャーを使って一時停止した場合、再開はトレイ・検索・キーなどから行います。

## 外部編集

0.26.35以降はMCPからメニューとシングル/ダブルクリック割当をまとめて取得・変更できます。形式と許可は[共通操作API](automation.md#タスクトレイ編集02635以降)が正本です。外部編集は設定保存だけを行い、割当コマンドをその場で実行しません。設定保存時は既存applySettingsが保留クリックを取り消し、実メニューを再構成します。シングルは1コマンド必須、ダブルはnullで解除できます。
