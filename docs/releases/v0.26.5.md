# AppDock.at365 v0.26.5

- Applet詳細の上部を「説明・設定・ショートカット・ログ」に整理しました。設定とキー編集を独立したタブで開けます。
- 設定ページの「Applet別の設定」をAppletページへ集約しました。全体のショートカットはAppDockを先頭に、Applet一覧と同じ順のグループで表示します。
- Applet一覧の「並べ替え」をONにすると、つまみのドラッグ・上下ボタン・上下キーで順を変更できます。保存後は再起動しても保持し、新しいAppletは末尾に表示します。WebAppletも対象です。
- 並び替えは表示順だけを変更し、リボンの配置、Appletの起動順、ショートカットの実行順は保持します。設定とショートカットの未保存入力はページ間で共有し、保存・破棄は全編集内容へ適用します。

Windows x64向けのインストール不要な単一EXEです。DLL型Appletは.NET 10 Runtime、独自WPF/WinForms画面のAppletは.NET 10 Windows Desktop Runtimeが必要です。既存の設定ファイルはそのまま利用でき、appletOrderがない設定では従来の発見順を使います。利用者が設定を旧版で保存し直した場合の新しい表示順の保持は保証しません。

通常のローカル発行はAppDock.at365.exeとupdate.jsonです。GitHub Releaseでは通常EXE・更新情報・全ローカルApplet入りZIPを配布する運用です。今回の変更だけではGitHub公開・実利用先への配置を行いません。検証結果と境界は[VERIFICATION.md](../../VERIFICATION.md)を参照してください。
