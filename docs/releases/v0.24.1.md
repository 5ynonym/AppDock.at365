# AppDock v0.24.1

Webアカウント管理を独立した設定ページへ移し、設定の保存を押さずに操作できるようにしました。GmailなどのWindows通知から、対応する配布版へ戻る起動経路も修正しています。

- アカウント枠の追加・名前変更・削除は即時反映します。名前はフォーカスを外す・Enter・ボタンで確定し、確定前のEscapeで元へ戻します。
- 枠の削除は警告で確認してから、保存データも消去します。使用中の保存ファイルは削除待ちを記録して、次回起動時に回収します。クリアは枠を残してログイン情報とサイトデータを消します。
- 枠の一覧を専用accounts.jsonへ分離し、0.24.0の設定からIDとログイン状態を保って自動移行します。Gmailのアカウントと保存領域は独立しています。
- 通知の起動経路をEXEの配置先・プロフィールごとに分け、テスト用の起動先と混ざる問題やコマンドの二重実行を防ぎます。
- オールインワンZIPの再発行時、前のZIPを保持して安全に置き換えます。

Windows x64と.NET 10 Desktop Runtimeが必要です。本体はインストール不要の単一EXEです。既存Applet API v1と個別更新の仕組みを維持し、Gmail Applet自体の更新は不要です。

配布物は通常版の`AppDock.at365.exe`、本体更新用の`update.json`、全ローカルApplet入りの`AppDock.at365-all-in-one-0.24.1.zip`です。通常版とZIP内の本体は同じファイルです。settings.json/.appdockを保持して更新し、全体ZIPのextensionsは新規導入または必要なAppletの更新に使ってください。

アカウント枠の移行後に0.24.0へ戻す場合は、完全終了後に専用accounts.jsonのaccounts配列をsettings.jsonのwebApplets.accountsへ戻す必要があります。旧版の削除記録がない残存フォルダーは自動削除しません。

通知の動作確認は、本体の更新・再起動後に新しく届いた通知で行ってください。更新前に表示された通知には、以前の起動先が残ります。

検証は型検査・本体回帰・隔離Web GUI・Cookie移行/分離/消去/削除後回収・既存ページ/Gmail・実単一EXE・全体ZIP・更新/復旧を対象にします。通知はWindows Shellからの起動と実Toastの表示/履歴で確認し、物理的な通知クリックと実Gmail受信は自動試験していません。実サイトのログインと長期背景動作は未検証です。
