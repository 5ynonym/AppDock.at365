# AppDock.at365 v0.26.13

一般設定に「スタートアップに登録」「常に管理者として起動」を追加しました。PowerToysと同様にユーザーのログオンタスクで起動し、登録後のサインイン時には毎回のUAC確認を出しません。現在の権限と実登録状態を確認でき、設定保存後に「管理者として再起動」も使えます。

既定はどちらもOFF。管理者設定は管理者ユーザーで使用します。管理者での登録・変更・解除と手動起動にはUAC確認が必要です。キャンセル/権限不足/保存失敗時には設定を保持します。EXE移動前は登録を解除してください。管理者設定OFFの反映には完全終了後の通常起動が必要です。

Windows x64、Electron 44.6.0、.NETのAppletホストは.NET 10 Runtimeが必要です。発行形式と保存先は従来のportable単一EXEを維持します。通常publishは本体EXEとupdate.jsonだけを作成します。検証範囲・未確認事項は[検証記録](../../VERIFICATION.md)、内部仕様は[起動設定](../launch-settings.md)を参照してください。
