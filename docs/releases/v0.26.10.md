# AppDock.at365 v0.26.10

- 「設定 → タスクトレイ」を追加し、クリック・ダブルクリックとメニュー編集をまとめました。
- コマンドをトップレベルや任意名のグループへ配置し、ドラッグ・上下操作で順番を変更できます。区切り線も追加できます。設定と終了は末尾に固定します。
- 「マウスジェスチャーを一時停止／再開」を本体コマンドにしました。検索やショートカットからも実行でき、トレイのチェック表示と連動します。
- 旧トレイ設定は初回に引き継ぎます。ショートカットの「トレイに表示」チェックは専用ページへ集約しました。

Windows x64向けのインストール不要な単一EXEです。DLL型Appletは.NET 10 Runtime、独自WPF/WinForms画面のAppletは.NET 10 Windows Desktop Runtimeが必要です。既存の設定を引き継いで更新できます。グループは1段で、一時停止状態は本体再起動で解除します。

ローカル発行物はAppDock.at365.exeとupdate.jsonです。GitHub Release時は通常EXE・更新情報・全ローカルApplet入りZIPを配布します。検証結果は[VERIFICATION.md](../../VERIFICATION.md)を参照してください。
