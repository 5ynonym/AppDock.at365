# AppDock.at365 v0.26.11

- 設定とAppletページ上部へ全変更の保存を統一しました。
- 未保存のまま別ページへ移動すると、画面を押し下げない上部の通知から保存・確認付き破棄ができます。
- WebAppletの追加/管理と新規サイト用ショートカット初期設定を、Applet一覧の組み込み「WebApplet」へ移しました。
- 別のAppletを選んでも説明・設定・ショートカット・ログの選択を維持します。
- 設定カテゴリを表示、一般、リボン、タスクトレイ、ショートカット、マウスジェスチャー、Webアカウント、プロフィール、バージョン情報・更新の順に揃えました。

Windows x64と.NET 10 Runtimeが必要です。配布形式はportable単一EXE、一般設定の保存形式とWeb/Gmailの認証領域は従来どおりです。EXEを同じフォルダーで更新し、settings.jsonと.appdockを保持してください。未保存の入力は再起動後には復元しません。

配布物は本体単一EXEの`AppDock.at365.exe`、自己更新用の`update.json`、本体と全6件のローカルApplet最新版を収録した`AppDock.at365-all-in-one-0.26.11.zip`です。新しくまとめて導入するときはオールインワンZIPを展開して起動し、使いたいAppletを有効にしてください。既存環境の更新は本体/各Appletの更新ボタンを使うと、個別に更新済みのAppletを古い版へ戻すことを避けられます。

本体回帰171件、設定/タブ保持/浮動通知/WebApplet/Gmailの隔離画面試験と単一EXE試験で確認しました。実サイト認証や実メール到着は今回の変更検証に含めていません。

GUIと配布EXEの実測範囲は[検証記録](../../VERIFICATION.md)を参照してください。
