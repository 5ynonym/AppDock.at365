# AppDock.at365 v0.26.9

- ショートカットの「…」メニューから「キーのクリア」を選べるようにしました。確認後に選んだ割り当てだけを解除し、保存すると再起動後も未設定のままになります。
- 無効な割り当てや停止中のAppletでもクリアできます。同じコマンドの別の割り当ては保持します。Deleteキーはショートカットとして割り当てられます。

Windows x64向けのインストール不要な単一EXEです。DLL型Appletは.NET 10 Runtime、独自WPF/WinForms画面のAppletは.NET 10 Windows Desktop Runtimeが必要です。既存の設定ファイルをそのまま利用できます。

ローカル発行物はAppDock.at365.exeとupdate.jsonです。GitHub Releaseでは通常EXE・更新情報・全ローカルApplet入りZIPを配布する運用です。検証結果は[VERIFICATION.md](../../VERIFICATION.md)を参照してください。
