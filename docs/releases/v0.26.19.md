# v0.26.19

- 設定ページのショートカットをキー別にまとめ、同じキー内の表示順と実行順を揃えました。提供元をまたいで上下移動・ドラッグできます。
- キーと条件を指定してからコマンドを選んで追加します。追加後も入力・検索・表示位置を保持し、自動スクロールしません。
- 行メニューを実行順の上下、コマンドの変更、確認付き削除の4項目に整理しました。
- Appletのショートカットタブは表示専用です。提供元の定義順で、各コマンドのキーと条件、未割り当て・無効状態を確認できます。
- 既存の保存形式、条件判定、同じコマンドの重複実行防止を維持します。WebApplet管理項目の新規サイト用テンプレートは引き続き編集できます。

Windows x64向けの単一EXEです。.NET Appletの利用には.NET 10 Runtimeが必要です。通常publishは本体EXEとupdate.jsonを生成し、全体ZIPはRelease時だけ作成します。検証範囲は[検証記録](../../VERIFICATION.md)を参照してください。
