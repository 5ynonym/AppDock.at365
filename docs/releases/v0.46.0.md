# AppDock.at365 0.46.0

## 主な変更

- Default Shellによるリボン・ページ・オーバーレイ・通知の描画と、領域ごとのShell割り当てに対応しました。
- 設定を即時保存へ統一し、Applet設定の一覧・検索、登録項目の追加・編集・並べ替え画面を共通化しました。
- 通知センター、種類別通知設定、音声通知、共通音声再生、TTSおよびAIテキスト生成の共通APIを追加しました。
- MCPとAppletの共通操作API、操作別権限、ネットワーク接続確認・認証案内を整備しました。
- WebAppletを独立Appletとして同梱し、サイト登録と動的なページ一覧に対応しました。
- モニター設定を番号付き一覧に統一し、選択ダイアログの表示と操作を改善しました。
- 設定ファイルの復旧案内、再起動通知、管理者起動時の通知連携、入力操作を改善しました。

## 配布物と導入・更新

Windows x64と.NET 10 Runtimeが必要です。Electron 44.6.0を使用します。

- `AppDock.at365.exe`: 本体のみ。終了後に既存EXEを置き換えるか、アプリ内更新を利用してください。settings.json・data・extensionsは保持してください。
- `update.json`: 本体のアプリ内更新用情報です。
- `AppDock.at365-all-in-one-0.46.0.zip`: 本体と全6Appletを含む新規導入用パッケージです。展開して起動し、必要なAppletを有効にしてください。

AppletはそれぞれのGitHub Releaseからも更新できます。WallpaperSlideshow 0.4.8は本体0.46.0以上、WebApplet 0.2.0は0.45.0以上、Gmail 0.11.0は0.42.0以上を必要とします。他の同梱Appletの最低本体版は0.36.8です。本体を先に更新してください。

既存のPC専用認証・キャッシュは端末別の保存領域を使用します。旧保存領域の案内が表示された場合はREADMEに従って確認してください。GitHubアカウント名変更前のURLはGitHubの転送を利用できます。

## 検証範囲と制約

リリース前に型チェック・標準回帰、新しく生成した本体の更新・進捗・取消・復旧と、全体ZIPの全ファイル照合・隔離起動・Applet一覧を検証します。公開後には匿名取得のサイズ/SHA256と実更新チェックを検証します。
実Googleログイン・メール受信、実壁紙変更、実際のOS終了・再起動/UAC操作や実利用先へのインストールはこのリリース作業の検証範囲に含みません。
