# AppDock 0.26.17

以前のsettings.jsonにWebAppletが残り、Webアカウント名簿が欠落または空の場合でも、設定のWebアカウントから枠を追加できるようにしました。WebAppletの設定で新しい枠を選び、変更を保存して利用を続けられます。起動時の空名簿の自動作成は行わず、追加前に届いた名簿や破損ファイルを上書きしません。

ホスト画面の操作エラーをログページとPC専用host.logに記録します。操作名とエラーメッセージを残し、元のエラー表示も維持します。

Windows 10/11 x64、単一EXE配布とdata/LOCALAPPDATAの保存境界は同じです。AppDockを完全終了しEXEを差し替えて起動します。旧フォルダーの自動移行・削除は追加していません。
