# AppDock.at365 v0.26.6

- ショートカットの表をマウスジェスチャーと同じ6列の構成へ揃えました。有効スイッチ、ドラッグ/上下キーによる並べ替え、行末の「…」メニューを使えます。
- 共通のコマンド選択から割り当てを追加できます。キーを指定してから保存し、TabやEscapeなどは特殊キーの選択欄で指定できます。選択中にコマンドは実行されません。
- 「…」から複製・確認付き削除・既定への復元・全体の実行順変更を行えます。両方の「…」列を細く揃え、追加ボタンとメニューのアクセント色/角丸を統一しました。
- Appletごとの表示順、保存済みのキー/条件、共有する未保存入力を引き継ぎます。グループ内のドラッグでは他のAppletの割り当て位置を保持します。

Windows x64向けのインストール不要な単一EXEです。DLL型Appletは.NET 10 Runtime、独自WPF/WinForms画面のAppletは.NET 10 Windows Desktop Runtimeが必要です。既存の設定ファイルをそのまま利用できます。

ローカル発行物はAppDock.at365.exeとupdate.jsonです。GitHub Releaseでは通常EXE・更新情報・全ローカルApplet入りZIPを配布する運用です。検証結果と境界は[VERIFICATION.md](../../VERIFICATION.md)を参照してください。
