# AppDock.at365 0.26.25

## 主な変更

- ショートカットとマウスジェスチャーを全コマンドの一覧へ統一しました。検索・割り当て状態の絞り込み、小さな編集パネル、同じ入力内の実行順を変更する専用パネルを利用できます。
- リボンのアバターの余白と画像の欠けを修正しました。
- 更新確認・取得中・完了の表示を、本文の位置を動かさないステータスバーへまとめました。通常結果は6秒で消え、操作中は表示を保ちます。詳細は更新画面の「確認結果」から開けます。
- 起動時の自動開始・遅延・管理者設定、PC間で共有する設定/登録素材と端末固有データの分離を追加しました。
- Webアカウント名簿の復旧、ホスト処理とApplet終了時のログを改善しました。
- WebApplet/GmailのWebViewがWindowsの優先言語を引き継ぐことを確認しました。サイト側の言語設定は変更しません。

## 配布物と更新方法

Windows x64と.NET 10 Runtimeが必要です。Electron 44.6.0を使用します。

- `AppDock.at365.exe`: 本体のみ。既存配置の設定・data・extensionsを残し、終了後にEXEを置き換えてください。アプリ内の更新も利用できます。
- `update.json`: アプリ内更新用の情報です。
- `AppDock.at365-all-in-one-0.26.25.zip`: 本体と全ローカルAppletを含む新規導入用パッケージです。展開してEXEを起動し、使用するAppletを有効にしてください。個別Appletは自身のReleaseからも更新できます。

旧版からの更新では、PC専用の認証・キャッシュ等は端末別の保存領域へ分離します。画面に旧保存領域の案内が出た場合は、確認後に設定同期を開始してください。設定と登録素材の扱いはREADMEの説明を参照してください。

## 検証範囲

型チェック・標準回帰、入力編集/ページ/更新の関連GUI、本体更新・キャンセル・復旧、全体ZIPの収録内容と隔離起動をリリース前に確認します。実アカウントの認証やメール受信、PCの再起動/UAC操作は検証範囲に含みません。個別Appletの最低ホスト版は各manifestに記載されています。
