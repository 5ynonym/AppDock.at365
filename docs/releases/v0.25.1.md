# AppDock v0.25.1

Applet詳細に横並びの「説明・設定・ログ」タブを追加しました。選択中のタブを色で示し、同じページ内で内容を切り替えられます。左右キーとHome/Endでも操作できます。

- ログは選択したAppletだけを表示し、検索とレベルで絞り込めます。リボンの全体ログとは独立しています。
- 設定の未保存入力はタブを切り替えても保持します。別のAppletを選ぶと説明へ戻ります。
- 明るい・暗いテーマと、小さいウィンドウでも3つのラベルを横並びで表示します。

Windows x64と.NET 10 Runtimeが必要です。本体はインストール不要の単一EXEで、Applet API v1を維持します。今回の表示改善に対応するために既存Appletを更新する必要はありません。各Applet固有の動作要件はそのAppletの案内に従ってください。

ローカル配布物は`AppDock.at365.exe`、`update.json`、全ローカルApplet入りの`AppDock.at365-all-in-one-0.25.1.zip`です。既存環境ではAppDockを終了してから本体EXEを置き換え、settings.jsonと.appdockを保持してください。ZIP全体は新規導入向けです。

型検査、隔離GUIでのタブ操作・設定保持・ログ絞り込み・レイアウト、WebApplet設定との往復、発行した単一EXEの起動と全体ZIPの整合を検証しています。実利用先への配置とGitHub公開は行っていません。
