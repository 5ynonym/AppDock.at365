# AppDock v0.24.2

停止したAppletのリボンアイコンを自動で隠すようにしました。WebAppletの停止後に残ったアイコンからエラーになる問題と、停止中のGmailがリボン操作で再び有効になる問題を修正しています。

- Appletページで無効にしたAppletは、Gmail・WebAppletを含めてリボンから消えます。
- 再開すると保存済みの表示・順序・上下配置へ戻ります。「設定 → リボン」の一覧には停止中も残り、配置を編集できます。
- 有効なAppletの開始待ちやエラー表示、コマンドの明示実行による起動は維持します。0.24.1のWebアカウント管理・通知起動先の改善も含みます。

Windows x64と.NET 10 Desktop Runtimeが必要です。本体はインストール不要の単一EXEです。Applet API v1と個別更新を維持し、Gmail Applet自体の更新は不要です。

配布物は通常版の`AppDock.at365.exe`、本体更新用の`update.json`、全ローカルApplet入りの`AppDock.at365-all-in-one-0.24.2.zip`です。通常版とZIP内の本体は同じファイルです。更新時はsettings.json/.appdockを保持してください。全体ZIPのextensionsは新規導入または必要なAppletの更新に使います。

Webアカウント枠は0.24.0の設定から自動移行し、Gmailのアカウントと保存領域は分離します。通知確認は更新・再起動後に届いた新しい通知で行ってください。

ユーザーによるローカル修正版の動作確認済み。リリース検証は型検査・本体回帰・隔離したWeb/Gmail/リボン配置GUI・実単一EXE・全体ZIP・更新/復旧を対象にします。実サイト認証・実Gmail受信・長期背景動作は今回の自動試験の対象外です。
