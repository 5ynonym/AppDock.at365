# AppDock 0.26.14

- 設定・共有Webアカウント枠・登録アセットと、PC専用の認証/実行状態の保存先を分離しました。PC専用データはLOCALAPPDATAへ保存します。
- 同期ファイルの安定待ち・定期照合と正常設定の20世代バックアップ、破損時の起動継続と確認付き復元を追加しました。
- 登録素材は元ファイル名で保存し、同名別内容を拒否します。アバターは登録原画像を残し、素材だけの変更も反映します。
- Gmail 0.9.2の登録済み通知音一覧を提供します。Gmailの専用枠と枠ごとの設定はPC専用です。
- 旧.appdockのPC専用データの自動移行・削除は行いません。旧データが残る場合は同期前の整理を案内します。
