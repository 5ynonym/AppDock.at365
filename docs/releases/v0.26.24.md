# AppDock 0.26.24

- 設定のマウスジェスチャーを、ショートカットと同じ全コマンド一覧へ統一しました。未割り当ての表示、検索、状態フィルター、＋からの追加、割り当てをクリックして編集できます。
- 編集パネルで移動・クリック・ホイールを選択でき、キーボードはキー記録と修飾キー付き特殊キー選択に対応します。ブラウザ/指定exe/指定Appletの条件、全体の動作設定も維持します。
- 同じジェスチャー内の実行順を専用パネルで変更できます。適用後は全体保存で確定し、取消と外部更新への上書き防止に対応します。削除は確認なしで編集内容へ反映します。
- 一覧・編集パネルの枠・実行順パネルを共通化し、既存ショートカットの操作と保存形式を維持しました。Windows x64/.NET 10 Runtime要件と単一EXEの配布方式は従来どおりです。
