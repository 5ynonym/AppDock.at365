# AppDock 0.26.16

EXE隣の共有データフォルダーを`.appdock`から小文字の`data`へ変更しました。WebAppletの枠は`data/web-applets/`、アバター原画像は`data/assets/profile/`、Appletの登録音声は`data/assets/applets/<Applet ID>/sounds/`へ保存します。

PC専用データは引き続き`%LOCALAPPDATA%/at365/AppDock/profiles/<配置ID>/`へ保存します。旧.appdockの自動移行・削除は行いません。既存の素材参照は読み取り互換を残し、新しい登録はdataへ保存します。単一EXEの配布とGmail 0.9.2のAPIは同じです。
