# AppDock 0.26.15

PC専用データの保存先を`%LOCALAPPDATA%/at365/AppDock/profiles/<配置ID>/`へ変更しました。更新用プログラムのjournal/resultも同じ場所を使用します。

登録するアバター画像は`.appdock/assets/profile/<元ファイル名>`へ保存します。ファイル名未指定のPNG登録もこの中のavatar.pngになり、EXE隣へ新しいavatar.pngを作りません。今後のAppletにも同期/端末固有の保存境界を適用します。

設定と登録素材の共有方法、GmailのPC専用枠、配置別の保存分離は0.26.14と同じです。Gmail 0.9.2を引き続き使用できます。旧保存先のデータの自動移行・削除は追加していません。
