# AppDock 0.26.20

Appletのショートカット一覧から、割り当てを追加・編集・削除できるようになりました。

- コマンド横の＋で追加、キーと条件をクリックして小さな編集パネルを開きます。
- 押したキーを大きく表示し、特殊キーはCtrl/Alt/Shiftと組み合わせて選べます。条件と有効状態も編集できます。
- 適用した内容は、画面上部の「変更をすべて保存」で保存します。キャンセルでは変更せず、連続追加でも一覧を自動スクロールしません。
- コマンドの提供元定義順を保ちます。Applet画面に実行順の操作は追加していません。
- キー入力中の誤実行、空の割り当て、編集中に外部更新された割り当てへの上書きを防ぎます。

設定ページのキー別編集と、WebApplet管理項目の新規サイト用テンプレートは継続して利用できます。
