# AppDock v0.24.0

URLからWebAppletを追加できるようになりました。Applet一覧・リボンから本体ページまたは別ウィンドウで開き、ページ遷移と認証先の許可を設定できます。

- WebApplet専用のアカウント枠を追加・選択し、ログイン状態を保存します。Gmailのアカウントと保存領域は分離します。
- Web側のmanifest/設定JSONから名前・アイコン・遷移の初期値を取り込めます。手動の変更は再取得で上書きしません。
- 追加・削除・無効化は再起動なしで反映し、リボン配置やキー設定を保持します。
- PNG/JPEG/WebPからアイコンを設定できます。

Windows x64と.NET 10 Desktop Runtimeが必要です。本体はインストール不要の単一EXEです。

配布物は通常版の`AppDock.at365.exe`、本体更新用の`update.json`、全ローカルAppletを同梱した`AppDock.at365-all-in-one-0.24.0.zip`です。通常版とZIP内の本体は同じファイルです。既存のsettings.json/.appdockを保持して更新してください。全体ZIPのextensionsは新規導入または必要なAppletの更新に使います。

WebAppletは最大64件、専用アカウントは32枠です。サイトの認証・デバイス権限・長期背景動作には対応範囲の制約があります。WebAppletは汎用ページ表示で、Gmailの新着監視機能は従来のGmail Appletが担当します。

検証範囲は型検査・本体回帰115件・隔離したWeb fixtureのGUI・ページ/ウィンドウ切替・Cookie分離/保存/消去・既存ページ/Gmail基盤・単一EXE/オールインワン配布・更新/復旧です。実サイトのログインと長期背景動作は未検証です。
