# AppDock v0.25.2

Appletごとにショートカットの初期値を宣言し、新しく導入したときにコマンド・キー・条件・有効状態を設定できるようにしました。既存の割り当てや、利用者が後から解除した割り当ては上書きしません。

- Gmail 0.9.1は次のアカウントにCtrl+Tab、前のアカウントにCtrl+Shift+TabをGmailページ条件で設定します。Watch 0.1.2は時計の切替にグローバルPauseを設定します。
- WebAppletの設定画面で、これから追加するWebAppletの初期割り当てを編集できます。既定はリロード=F5、戻る=Alt+左、進む=Alt+右です。コマンド名の「再読み込み」を「リロード」に改めました。
- Applet詳細の「ショートカットキー」で、そのAppletの割り当てをまとめて初期値へ戻せます。保存前なら取り消せます。

Windows x64と.NET 10 Runtimeが必要です。本体はインストール不要の単一EXEで、Applet API v1を維持します。Gmail 0.9.1とWatch 0.1.2は古いAppDockでも従来の機能を使えますが、新しい初期割り当てを自動設定するにはAppDock 0.25.2以降が必要です。

ローカル配布物は`AppDock.at365.exe`、`update.json`、全ローカルApplet入りの`AppDock.at365-all-in-one-0.25.2.zip`です。既存環境ではAppDockを終了してから本体EXEと必要なAppletフォルダーを置き換え、settings.jsonと.appdockを保持してください。ZIP全体は新規導入向けです。

型検査と全体回帰136件、隔離GUIでの初回割り当て・一括初期化・WebAppletテンプレート変更・実Windowsキー、単一EXEの起動と全体ZIPの整合を検証しました。実利用先への配置とGitHub公開は今回のローカル発行に含めていません。
