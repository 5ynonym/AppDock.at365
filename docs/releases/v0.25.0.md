# AppDock v0.25.0

ショートカット設定を、コマンド・キー・「いつ・どこで」を並べる一覧表へ刷新しました。GmailやWebAppletごとに使えるキーを選び、同じキーから条件に合う複数のコマンドを実行できます。

- 条件はグローバル、AppDock全体、すべてのApplet、提供元のApplet、指定したAppletから選択できます。提供元は「Gmail」など名前だけを表示し、指定したAppletは複数選択できます。
- Appletコマンドへの新規キー割り当ては提供元のAppletを既定にします。本体コマンドはAppDock全体が既定です。既存条件の編集や複製では設定を維持します。
- 同じキーで一致したコマンドを保存順に実行します。同じコマンドは1回だけ実行し、キー送信による再入を防ぎます。有効/無効、実行順、複数割り当てを編集できます。
- コマンドIDを省略せず表示します。ショートカット一覧、コマンド検索、ホームのピン留め、トレイ動作選択で確認でき、コマンド名・Applet名・IDによる検索を維持します。
- 本体ページ、Gmailの画面と本文、WebAppletの埋め込み/別ウィンドウで共通の条件を使用します。旧形式の設定は新形式がない場合に読み込み、既存キーを引き継ぎます。

Windows x64と.NET 10 Desktop Runtimeが必要です。本体はインストール不要の単一EXEです。Applet API v1を維持し、既存Appletの更新は不要です。このショートカット基盤には本体0.25.0以降が必要です。

配布物は通常版の`AppDock.at365.exe`、本体更新用の`update.json`、全ローカルApplet入りの`AppDock.at365-all-in-one-0.25.0.zip`です。通常版とZIP内の本体は同一です。既存利用時は本体の更新機能または終了後のEXE置換を使い、settings.json/.appdockを保持してください。同梱extensionsは新規導入または必要なAppletの更新に使います。

AppletのWeb画面では文字入力保護のためCtrl/Alt付き、F1〜F24、Pauseを受け付けます。IME変換中・キー記録中・リピート入力はローカル実行から除外します。native Appletの独自WindowはAppletページ条件に含めません。新形式を旧版で編集する往復互換は保証しません。

検証対象は型検査・本体回帰・ショートカット/設定/ページの隔離GUI・実Windowsホットキー・単一EXE・全体ZIP・更新/復旧です。実サイト認証、実Gmail受信、すべての物理キーボード配列とIMEの組合せは自動検証の対象外です。
